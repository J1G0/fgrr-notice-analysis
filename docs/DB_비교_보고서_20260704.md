# FGRR 고시 DB vs Excel 비교 보고서

작성일: 2026-07-04 (최종 갱신)
기준 Excel: `docs/FGRR_DB_0605.xlsx` (4,770행, 유전자원보호구역 전용)
기준 DB: PostgreSQL `fgrr_notices` 테이블 (라이브 접속, `DATABASE_URL` 경유, 현재 4,632행)
비교 방법: `.env`의 `DATABASE_URL`로 로컬 PostgreSQL(`research` DB)에 `psycopg2`로 직접 접속하여 `GROUP BY "번호"`, `GROUP BY "번호", "유전자원보호구역_여부"` 쿼리 결과를 Excel 파싱 결과와 대조함.

> **이 문서는 하루 동안 여러 차례 갱신되었다.** 최초 6/30 보고서 재검증(덤프 파싱) → 라이브 DB 재확인 → 0592 재입력 → 사용자의 수동 정리(8개 번호 삭제 + 다수 번호 행수 정리) → 0830 오류 수정 → 0101/0102/0178/0428 추출 실패 발견 → 0461/0731/0736/0754 재확인(추출 실패 추가 확인)까지의 전체 이력은 **5장**에 정리했다. 아래 1~4장의 수치는 **작성 시점 최신 상태** 기준이다.
>
> **주의**: DB는 사용자가 DataGrip 콘솔에서 이 보고서를 참고해 실시간으로 계속 정리 중이라, 아래 수치는 스냅샷이며 이후 다시 바뀔 수 있다. 정확한 현재값은 6장 부록 쿼리로 직접 재조회하는 것을 권장한다.
